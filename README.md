# Brantesh Jala Solution Technologies — Business Website

## Included
- Responsive, professional single-page business website
- HTML + CSS + JavaScript only (no backend required for the demo)
- Solutions: Water Softener/Conditioner, RO Plant, STP, ZLD, Sand & Carbon Filtration, Domestic/Building Water
- Technology section using the supplied company video
- Company profile section using the supplied brochure image
- Responsive navigation, scroll animations, counters, enquiry form UI
- Mobile-friendly layout

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Important
The enquiry form is front-end demo functionality. It does not send/store data.
For a production deployment, connect it to a backend/API, email service, CRM, or form provider.

## Source basis
Company history, CDLPT/natural water conditioning, hard-water benefits, agriculture/dairy/poultry/pool applications, and sand/carbon filter specifications are based on the supplied company presentation. STP/RO/ZLD were included because they were explicitly requested for the website brief.


## Visual imagery
The founder portrait is cropped from the founder/company profile page supplied by the user. The four solution cards use representative real-world reference photos from Wikimedia Commons under their stated Creative Commons licenses; the site labels them as reference imagery so they are not presented as Brantesh Jala project photographs.
